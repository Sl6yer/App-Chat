Chat App com Firebase e Google Sign-In

Este é um aplicativo de chat simples que utiliza o Firebase para autenticação e armazenamento de dados, e o Google Sign-In para login. Os usuários podem enviar mensagens de texto e imagens em tempo real. A aplicação é construída com Flutter e integra-se com o Firebase para gerenciar a autenticação e o armazenamento de mensagens.

## Funcionalidades

- **Autenticação com Google**: O usuário pode fazer login usando sua conta do Google.
- **Envio de Mensagens**: Envie mensagens de texto e imagens.
- **Armazenamento no Firebase**: Mensagens e imagens são armazenadas no Firestore e Firebase Storage.
- **Exibição de Mensagens em Tempo Real**: As mensagens enviadas são exibidas em tempo real para todos os usuários conectados.
- **Interface de Chat**: Interface simples e limpa para envio e exibição das mensagens.

## Tecnologias Utilizadas

- **Flutter**: Framework para construção de aplicativos móveis.
- **Firebase**:
- **Firebase Auth**: Para autenticação de usuários.
- **Cloud Firestore**: Para armazenar e recuperar mensagens.
- **Firebase Storage**: Para armazenar imagens enviadas pelos usuários.
- **Google Sign-In**: Para permitir que os usuários se autentiquem com suas contas do Google.
